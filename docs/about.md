# About NJ Civic Info

NJ Civic Info is an open-source project dedicated to making civic information in New Jersey more accessible to all residents.

## Goals

- **Accessibility**: Make civic information easy to find and understand
- **Accuracy**: Provide up-to-date and verified information
- **Openness**: Maintain an open-source, community-driven project

## Scope

This project covers civic information for the state of New Jersey, including:

- Elected officials at local, county, and state levels
- Voting and election resources
- Government services and contact information
- Public meeting schedules and records

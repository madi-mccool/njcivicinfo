# NJ Civic Info

Welcome to **NJ Civic Info** — a resource for civic information in New Jersey.

## What is NJ Civic Info?

NJ Civic Info provides accessible, up-to-date civic information for New Jersey residents, including details about elected officials, voting resources, and government services.

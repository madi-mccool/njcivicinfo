# NJ Civic Info

Civic information resources for New Jersey residents.

## Documentation

The documentation site is built with [Jekyll](https://jekyllrb.com/) and deployed via [GitHub Pages](https://pages.github.com/).

**Live site**: [https://madi-mccool.github.io/njcivicinfo/](https://madi-mccool.github.io/njcivicinfo/)

### Local development

To run the docs site locally:

```bash
cd docs
bundle install
bundle exec jekyll serve
```

Then visit `http://localhost:4000/njcivicinfo/` in your browser.
